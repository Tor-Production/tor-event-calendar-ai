Upgrade, uninstall and troubleshooting

Install the next exact release tarball and reinstall the skill with tor-calendar install-skill CLIENT. Profiles survive upgrades/uninstalls. The installer preserves unowned skills and junctions.

Use tor-calendar doctor for public service/keychain checks. Locked/unavailable keychain fails safely. Explicit headless secret-manager injection is documented; no plaintext fallback is automatic.

tor-calendar uninstall-skill CLIENT removes only this installer's skill. disconnect --account SELECTOR revokes that connection. npm uninstall -g tor-event-calendar-ai removes the CLI.
