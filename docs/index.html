Nembli for Codex

Your calendar, one conversation away.

Open Nembli in Codex, connect your calendar, and ask for what you need.

Open Nembli in CodexFirst-time setup

The button opens Nembli from your Personal marketplace. If it is missing, use the setup help below.

Connect in three steps

1. Open Nembli

In Codex, open the Nembli plugin by Tor Production. Choose Connect if requested.

2. Choose your calendar

Sign in in your browser. Check your calendar account and the requested permissions, then choose Allow access.

3. Start a conversation

Start a new Codex chat and try the request below.

Your first request

Use Nembli to show my connected account and today's events in Europe/Kyiv.

Change Europe/Kyiv if you use another timezone.

Setup help and first installation

Nembli is not in Codex yet

Open Codex plugins

In the plugin browser, add the GitHub marketplace https://github.com/Tor-Production/tor-event-calendar-ai, then find Nembli by Tor Production and install it. If your Codex version offers custom MCP setup instead, follow the steps below.

Nembli's public OpenAI directory listing is still a draft. The GitHub installation is a separate route.

Open public Nembli listing
Connect the calendar manually
  1. Open Settings → Plugins → MCPs → Add → custom MCP.
  2. Name the connection Nembli, select Streamable HTTP, and paste the server URL below.
  3. Connect, sign in, and review the calendar account before allowing access.
https://nembli.com/mcp

Manual setup connects the calendar tools. It does not install the packaged skill.

Codex does not open from the button

Start the Codex desktop app, open Plugins, and select Nembli. If it is missing, use the first installation steps above.

Update an older Nembli installation

Refresh the plugin to receive the approved Nembli logo. The next plugin update renames the old Tor-event-calendar MCP connection to Nembli; Codex may ask you to connect again. Check the calendar account before allowing access.

Optional local helper

The remote plugin needs no terminal or local helper. If you choose the advanced CLI route, follow the local connection reference.

Let me finish sign-in and account consent in my browser. Then verify the connection by showing my connected account and today's events in Europe/Kyiv. Claude Code

Run the command below, then open /mcp in Claude Code and authenticate Nembli in your browser.

claude mcp add --transport http nembli https://nembli.com/mcp

Claude web and Desktop

Open Customize → Connectors, add a custom connector named Nembli with the server URL below, then connect it. Enable it for your conversation. Custom connectors depend on your plan and workspace permissions.

https://nembli.com/mcp

Cursor

Merge this entry into your global ~/.cursor/mcp.json or project .cursor/mcp.json. Open the MCP settings and connect Nembli to finish browser sign-in.

{
  "mcpServers": {
    "nembli": { "url": "https://nembli.com/mcp" }
  }
}

Official Cursor instructions

VS Code / GitHub Copilot

Run MCP: Add Server from the Command Palette. Choose an HTTP server, enter the URL below, name it nembli, and choose where to save it. Start the server and finish authentication when prompted.

https://nembli.com/mcp

Official VS Code / GitHub Copilot instructions

GitHub Copilot CLI

Run the command below, then open /mcp in Copilot CLI to check the server and finish authentication.

copilot mcp add --transport http nembli https://nembli.com/mcp

Official GitHub Copilot CLI instructions

Gemini CLI

Merge this entry into ~/.gemini/settings.json. Restart Gemini CLI, then run /mcp auth nembli to complete browser sign-in.

{
  "mcpServers": {
    "nembli": { "httpUrl": "https://nembli.com/mcp" }
  }
}

Official Gemini CLI instructions

Hermes Agent

Merge this entry into ~/.hermes/config.yaml. From a fresh terminal, run hermes mcp login nembli and finish browser sign-in. Restart your chat to load the connection.

mcp_servers:
  nembli:
    url: "https://nembli.com/mcp"
    auth: oauth

Official Hermes Agent instructions

Another client, or remote MCP is unavailable
  1. Find your client's MCP or connector settings and add a remote server named Nembli.
  2. Choose Streamable HTTP, use https://nembli.com/mcp, and connect using browser OAuth.
  3. Review your calendar account, allow access, then ask Nembli to confirm the connected account.

If your client does not support this flow, use the optional local helper. Its installation supports Codex, Claude, Cursor, GitHub Copilot CLI, Gemini CLI, and Hermes.

Merge configuration examples with existing settings. Manual MCP setup connects calendar tools; the packaged skill is a separate optional installation.

No Nembli connection yet? Use the setup instructions above first. The server cannot read a chat attachment until your client supplies a supported file transfer. A browser upload link still requires you to select and upload the file; ask your AI to verify the saved attachment afterward. File workflow and downloads

To attach a file, add it to your chat and ask Nembli which event and File field to save it to. Supported Codex and ChatGPT hosts transfer it directly; clients without attachment support can use the signed-in calendar upload page.

Calendar access lets Codex find and manage your entries, drafts, and named files. Calendar actions never publish or schedule social posts. Changing the website login does not change an existing Codex connection. Review or revoke it in Connections & tokens.
