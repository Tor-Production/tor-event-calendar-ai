# nambli release notes

## 0.3.3-dev.4 development candidate

Adds Instagram, Facebook, YouTube, TikTok and Snapchat to the shared calendar planning registry, REST/MCP schemas and portable planner. Minimal human-facing account/content choices persist across edits; all five automatic adapters remain unsupported. Matching server changes recognize selected public permalink forms for confirmed manual receipts and recovery without reposting. No social API integration, new platform notification integration or real send is included. Core explicit invocation, plugin IDs, stable v0.3.2 and the submitted catalog archive remain unchanged.

## 0.3.3-dev.3 development candidate

Adds portable `nambli-content` and `nambli-publish` workflows alongside the explicit-only core calendar skill. Content creation uses the user's available tools and saves drafts only when requested. Authorized publication uses a separately available publisher, records a confirmed receipt and permalink immediately, and retries calendar synchronization without reposting. Confirmed posts with a missing permalink have an explicit recovery path. New coordination/result tools require the matching deployed calendar server.

The combined plugin, npm tarball and Claude Code package include all three skills; each skill also has a standalone ZIP. This candidate retains the Claude Code identity migration and optional local-file helper introduced in dev.2. No social publisher, shared credentials or owner-private app binding is bundled. Native Codex + LinkedIn send acceptance and OpenAI catalog publication remain separate from package validation. Stable v0.3.2 assets and their historical evidence below are unchanged.

## 0.3.2

Version 0.3.2 improves selected-account verification and account-management guidance. Account status now calls the selected connection's `get_profile`; remembered chat identities or website sessions are not treated as the current plugin account. Where the host supports multiple accounts, the skill directs users to its account controls without replacing their existing connection or embedding an owner's private app URL.

Unsupported public calendar sharing, email search and pure date arithmetic require no nambli lookup. The five positive and three negative review cases now match the current English walkthrough, including typed unpublished draft settings and an actual saved-file download comparison. The original blue/purple logo, explicit-only skill invocation, stable package/CLI IDs, and https://nambli.com/mcp endpoint are preserved. Calendar writes never publish or schedule social posts.

The release includes the combined plugin ZIP, standalone nambli skill ZIP and optional CLI tarball. `nambli-store-0.3.2.zip` is the unchanged, minimal public ZIP already uploaded to the OpenAI Portal; the repository distribution additionally contains public setup guides, marketplace metadata and test/build tools. Shared tool source, skill instructions, manifests and artwork match the Portal package. Only release documentation and package build metadata differ among their overlapping files. All release downloads have SHA-256 entries; no private app binding or reviewer credential is included.
