# nambli 0.3.0 candidate release notes

The product changes from Nembli to nambli at nambli.com. A new remote MCP origin requires fresh registration and account consent. Old connections and local profiles retain their original origin; no token migration or redirect-based OAuth transfer occurs. Repository, npm package, skill and CLI IDs remain stable.

This source integrates PR #15 file workflow/download guards and PR #14 Claude Code packaging. get_file_download is a read-only delivery plan, with bounded native resources and authenticated browser/local fallback. Exactly five positive and three negative cases include actual upload, download, open and byte comparison.

The package uses owner-approved Nambli Bold 0.7.3 artwork. The full font family is not included in the public package. Existing v0.2.4 release assets remain unchanged.

This is technical preparation, not a catalog submission or publication receipt. New videos, recorded host execution and owner legal attestations are pending. The old 0.2.3 review cancellation remains unverified.
