# nambli 0.3.0 release notes

The product changes from Nembli to nambli at nambli.com. A new remote MCP origin requires fresh registration and account consent. Old connections and local profiles retain their original origin; no token migration or redirect-based OAuth transfer occurs. Repository, npm package and CLI IDs remain stable. The explicit-only skill is renamed to nambli; CLI-managed legacy skills are backed up outside discovery, and owner-managed junctions are preserved for deliberate migration.

This source integrates PR #15 file workflow/download guards and PR #14 Claude Code packaging. get_file_download is a read-only delivery plan, with bounded native resources and authenticated browser/local fallback. Exactly five positive and three negative cases include actual upload, download, open and byte comparison.

The original blue/purple gradient n logo is retained unchanged. The lowercase wordmark uses owner-approved Nambli Bold 0.7.3 artwork; the full font family is not included in the public package. The public setup guide adds direct Cursor, VS Code and Insiders installation links with manual fallbacks and explicit account consent. Existing v0.2.4 release assets remain unchanged.

This GitHub package release is separate from OpenAI catalog submission and publication. New review and product edits are live at https://nambli.com/demo and https://nambli.com/product-demo. Review footage still needs successful draft persistence, actual saved-file download/open/comparison and a clean negative publication case. The recording guide gives exact steps. Native post-restart acceptance and owner legal attestations remain separate gates; no passing model or catalog review is claimed.
