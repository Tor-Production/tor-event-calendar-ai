## Reproduce local validation

From a clean source checkout with Node 22.18+ and Python, run `npm ci --ignore-scripts`, `npm test`, `npm pack --pack-destination dist`, `python scripts/package.py`, and `python scripts/test_package.py`. The committed icon assets already match the deterministic generator. The ZIP checks compare packaged files against source, confirm the Nembli endpoint/metadata and unpublished install state, and verify `dist/SHA256SUMS`. Tests use synthetic profiles and do not connect a real account or publish content. Rebuild after any packaged source edit.

The [OpenAI submission guide](https://developers.openai.com/plugins/deploy/submission) distinguishes the With MCP flow from local packaging: supply the HTTPS server URL and upload/import the skill. The full portable ZIP supports local distribution; a Skills-only upload excludes MCP configuration. The [installation-page source](../docs/index.html) and [calendar-site handoff](calendar-site-handoff.md) keep the pending directory state visible and manual MCP as a separate tools-only fallback.
